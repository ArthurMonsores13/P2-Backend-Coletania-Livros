API Cadastro de Filmes - Por Arthur Monsores

Esse Sistema sera feito em DJANGO com banco em postgreSQL conectado via docker

ONde voce pode adicionar,editar e excluir seus filmes eu fiz um template para eles onde é so acessar e clicar

Como instalar

Utilize o comando 'docker pull arthurmonsoresdev/p2-back-web' para baixar a imagem do projeto e rodar

As url sao: 
Principal : http://localhost:8000/
Cadastrar : http://localhost:8000/cadastrar/
Buscar por nome : http://localhost:8000/buscar/<nome>

Voce pode editar e excluir tambem
